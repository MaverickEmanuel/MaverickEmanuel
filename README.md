## Hi, I'm Maverick 👋

I'm an AI developer in Toronto. I build LLM agents, MCP servers and RAG systems, mostly in TypeScript and Python on AWS.

Over the past year I've built enterprise MCP servers, worked on an internal platform for building agent workflows, and written custom LLM guardrails. A lot of that work was the stuff around the model: auth, rate limits, evals, and tool descriptions that an agent can actually use.

### 🌱 Personal projects

- [DemoPilot](https://github.com/MaverickEmanuel/DemoPilot): an open-source MCP server that guides an AI agent through authoring a product demo. It drives the app via Playwright, locates elements by their role and name, records each step in a validated YAML script, and replays it deterministically to an MP4 with Remotion.
- [trusted-skill-scout](https://github.com/MaverickEmanuel/trusted-skill-scout): finds agent skills for a repo and filters them by trust before you install anything.
- [ai-ready](https://github.com/MaverickEmanuel/ai-ready): a Claude Code skill that sets up a repo for agentic coding in one command.
